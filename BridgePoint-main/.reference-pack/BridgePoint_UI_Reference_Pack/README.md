## Design rule
Keep the current BridgePoint visual identity:
- clean white/light backgrounds
- BridgePoint blue as the primary action color
- restrained blue/purple gradients
- rounded cards
- subtle shadows
- generous spacing
- consistent typography and iconography

The AI, GIS, blockchain, welfare, payment and cooperative functions should appear naturally inside the product workflow rather than becoming disconnected "technology showcase" pages.
